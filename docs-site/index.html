04

A minute in the app

  1. Dashboard. Today’s route, quick stats, recent activity.
  2. Route today. Tap a stop → Start visit (GPS captured). Finish customer work.
  3. Invoice. Type item name or barcode, pick rate, discount inline, Submit.
  4. Print. Tap Print on the invoice detail — Android’s system print dialog handles the rest.
  5. Payment. Collect cash or card against the invoice. Signature optional.
  6. End visit. GPS captured again, notes saved, stop marked done.
  7. Complete route. Always-visible button on the Route screen. Opens the daily summary.
05

Questions

Can I use this with my own ERPNext?

Yes — the backend is a Frappe app (vansale) and the APK is a thin Capacitor wrapper. Point the build at your server’s base URL and rebuild; contact Enfono for the installer.

What happens to queued work when offline?

Visits, invoices and payments land in an IndexedDB queue. The app drains them in order when a connection returns — a sync indicator in the top bar shows pending count.

Does print need Bluetooth setup?

No. Print uses Android’s system print service, which already knows about your printers (Bluetooth, Wi-Fi, or Save as PDF). The app just hands the dialog a PDF.

Is the demo data reset?

The demo site is shared and persistent between visitors. Please don’t enter sensitive data. The site is rebuilt on request if it gets cluttered.
