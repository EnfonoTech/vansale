# Van Sale — Phase 5: Capacitor Native + Rollout — Implementation Plan

> REQUIRED SUB-SKILL: superpowers:subagent-driven-development / superpowers:executing-plans.
>
> **Inherits:** All Phase 1–4 patterns + `frappe-vue-pwa` §3.9 Capacitor shell + §5 commandments.

**Goal:** Ship a signed Android APK that bundles the Phase 1–4 Vue source, matches the web PWA byte-for-byte in behaviour, and wires every native plugin correctly. Mirror the Fateh HR `build-customer.sh` pipeline. Deliver first demo APK to a named customer tenant, verify deploy, document rollout.

**Architecture:** `android-capacitor/` symlink-sourced shell → `npx cap sync android` → `gradlew assembleRelease`. Keystore reused across versions (commandment #17). `bump-version.mjs` is the only path for `NATIVE_VERSION` + `versionCode` (commandment #15).

**Tech:** Capacitor 6, Android SDK 34, Gradle, keytool/apksigner.

## Tasks

- [ ] `mkdir android-capacitor && cd android-capacitor && pnpm init`, `pnpm add @capacitor/core @capacitor/cli @capacitor/android` (+ all plugins the app uses from P1–P4: `@capacitor/app`, `@capacitor/camera`, `@capacitor/filesystem`, `@capacitor/geolocation`, `@capacitor/network`, `@capacitor/preferences`, `@capacitor/splash-screen`, `@capacitor/status-bar`, `@capacitor-mlkit/barcode-scanning`, `@capacitor-community/bluetooth-le`). Dev-deps: `vite`, `@vitejs/plugin-vue`, `typescript`.
- [ ] `ln -s ../frontend/src src`.
- [ ] Write `capacitor.config.ts` per §3.9 (appId `com.enfono.vansale.<customer>`, scheme `https`).
- [ ] Write `vite.config.ts` — `preserveSymlinks: false` (§5 rule 13), `base: "./"`, `outDir: "www"`.
- [ ] Write `index.html` loading `./src/main.ts`.
- [ ] **Commit** `feat(capacitor): shell + symlinked Vue source`.

### Task 2 — Native bootstrap in main.ts

- [ ] Update `frontend/src/main.ts` with the §3.10 native bootstrap block (SplashScreen, StatusBar, App back-button listener, Network auto-init). Static imports only — `frappe-vue-pwa` §3.4 rule 14.
- [ ] Write `src/app/native-back.ts` with `PARENT_BY_ROUTE_NAME` route-hierarchy map (§fatehhr lesson #8). Home → "press back again to exit".
- [ ] Wire `saveBlobToDevice()` fully: native → `Filesystem.writeFile` with sanitised filename (§fatehhr lesson #12); web → anchor fallback.
- [ ] **Commit** `feat(native): bootstrap + back button + Filesystem downloads`.

### Task 3 — Add Android project

- [ ] `cd android-capacitor && pnpm build && npx cap add android && npx cap sync android`.
- [ ] Manifest: add INTERNET, CAMERA, BLUETOOTH_* (P4), ACCESS_FINE_LOCATION (P4), READ_MEDIA_IMAGES, maxSdkVersion READ_EXTERNAL_STORAGE.
- [ ] **Commit** `feat(android): initial project generation`.

### Task 4 — Keystore

- [ ] `scripts/generate-keystore.sh` — `keytool -genkey -keystore vansale-release.keystore -alias vansale -keyalg RSA -keysize 2048 -validity 10000 -storetype PKCS12`. Password file at `~/.vansale-keystore-pw` with `VANSALE_KEYSTORE_PW=...` + `VANSALE_KEY_PW=...` (same password — PKCS12 limitation, §fatehhr lesson §5.1).
- [ ] Back up keystore twice (§commandment #17). Never commit.
- [ ] Document storage location in `docs/AGENT_HANDOFF.md`.
- [ ] **Commit** `chore(signing): keystore generator`.

### Task 5 — Gradle signing wiring

- [ ] Write `scripts/_patch-build-gradle.py` (port from fatehhr) — **replaces** default release config; never appends (§fatehhr lesson §5.1).
- [ ] Wire `signingConfigs.release` using env vars `VANSALE_KEYSTORE_PW` / `VANSALE_KEY_PW`.
- [ ] **Commit** `feat(signing): Gradle signing config patcher`.

### Task 6 — Version bumper

- [ ] Write `scripts/bump-version.mjs` — atomically bumps `frontend/src/app/native-version.ts` (`NATIVE_VERSION`) AND `android-capacitor/android/app/build.gradle` `versionCode`/`versionName`. Semver arg: `patch` / `minor` / `major`.
- [ ] Refuse to commit if either value is already ahead of git (safety).
- [ ] **Commit** `feat(versioning): bump-version.mjs atomic bumper`.

### Task 7 — Customer asset generator

- [ ] Write `scripts/generate-customer-assets.mjs` — reads `customers/.env.<id>`, generates: `android/app/src/main/res/mipmap-*/ic_launcher.png` (icon resize from 1024px source), `colors.xml` (overwrite, never append — §lesson §5.1), `strings.xml` appName, `splash.png`.
- [ ] Include theme-plugin update so PWA + APK share colours.
- [ ] **Commit** `feat(whitelabel): customer asset generator`.

### Task 8 — build-customer.sh

- [ ] Write `scripts/build-customer.sh` — one command: bump version → `CUSTOMER_BUILD_TARGET=native pnpm exec vite build` → `generate-customer-assets.mjs` → `npx cap copy android` → **IF** the set of plugins changed, `npx cap sync android` → `./gradlew assembleRelease` → `dist/vansale-<customer>-<version>.apk`.
- [ ] Honours `~/.vansale-keystore-pw` if present, env vars otherwise.
- [ ] Refuses to proceed if git has uncommitted changes (safety).
- [ ] **Commit** `feat(deploy): build-customer.sh pipeline`.
