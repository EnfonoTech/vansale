# User guide screenshots

Drop PNGs here and both guide surfaces pick them up automatically — the desk page
**SF Trading User Guide** and the public **/user-guide**. No code change, no rebuild: the
controller adds a "Screens" section for whichever files exist, so a missing screenshot simply
does not appear (nothing renders broken).

Use these exact filenames:

| Filename | What to capture |
|---|---|
| `payment-advice-form.png` | A Payment Advice with references fetched, showing the allocation headline |
| `get-outstanding-dialog.png` | The Get Outstanding Documents dialog |
| `builder-preview.png` | Payment Advice Builder with suppliers grouped and the skipped list |
| `builder-result.png` | The result panel after creating advices |
| `automation-settings.png` | Payment Automation Settings — four steps and the plan sentence |
| `automation-dry-run.png` | A Dry Run summary |
| `workflow-actions.png` | The PM Workflow actions on a submitted advice |
| `advice-list.png` | The Payment Advice list, colour-coded by status |

`.jpg`, `.jpeg` and `.webp` also work. Full-window captures at a normal desk zoom read best.
